# my-first-python 🐍

أهلاً بيك في أول خطوة ليك في عالم البرمجة! الريبو ده معمول عشان تتعلم بايثون خطوة بخطوة، من غير تعقيد.
Welcome! This repo is your first step into programming with Python, in simple small steps.

## إيه اللي جوه؟

| الملف | إيه فكرته |
|------|-----------|
| `hello.py` | أول برنامج تشغّله: بيسلم عليك بالاسم |
| `exercises/01_variables.py` | المتغيرات والطباعة (مبتدئ جدًا) |
| `exercises/02_conditions.py` | الشروط if / else (مبتدئ) |
| `exercises/03_loops.py` | الحلقات for وجدول الضرب (مبتدئ+) |

## إزاي تشغّل الأكواد؟

1. نزّل Python من [python.org](https://www.python.org/downloads/)
2. افتح الترمينال في مكان الملف
3. شغّل: `python hello.py`

## نصيحة 💡

متخفش تبوّظ الكود. غيّر فيه، شغّل، شوف النتيجة. كده بالظبط اللي بيتعلم بيها أي مبرمج.

خطوة بخطوة وانت كده مبرمج 🚀
