# my-first-python 🐍

أهلاً بيك في أول خطوة ليك في عالم البرمجة! الريبو ده معمول عشان تتعلم بايثون خطوة بخطوة، من غير تعقيد.
Welcome! This repo is your first step into programming with Python, in simple small steps.

## إيه اللي جوه؟

| الملف | إيه فكرته |
|------|-----------|
| `hello.py` | أول برنامج تشغّله: بيسلم عليك بالاسم |
| `quotes.py` | برنامج الاقتباسات: بيعرضلك اقتباس عشوائي في كل مرة |
| `quotes.txt` | ملف الاقتباسات اللي البرنامج بيقرأ منه (تقدر تضيف فيه بنفسك) |
| `exercises/01_variables.py` | المتغيرات والطباعة (مبتدئ جدًا) |
| `exercises/02_conditions.py` | الشروط if / else (مبتدئ) |
| `exercises/03_loops.py` | الحلقات for وجدول الضرب (مبتدئ+) |

## برنامج الاقتباسات 📖

ده تاني برنامج ليك، وأول خطوة في مشروعك الكبير: برنامج بتحفّيه اقتباساتك المفضلة من الكتب، وبيعرضلك واحد عشوائي في كل مرة تشغّله.

- الاقتباسات محفوظة في ملف `quotes.txt` بشكل بسيط تقدر تعدّله بإيدك: كل سطر فيه اقتباس، واسم المؤلف، والكتاب لو معروف. فيه حوالي ٣٠ اقتباس من الأدب العربي جاهزين كبداية.
- البرنامج `quotes.py` بيقرأ الملف ويختار اقتباس عشوائي ويطبعه مع اسم صاحبه.
- شغّله بنفس طريقة `hello.py`: افتح الترمينال في مكان الملف واكتب `python quotes.py`

ضيف اقتباساتك المفضلة في `quotes.txt` كل ما تقرأ حاجة تعجبك، وبعدين هنطوّر البرنامج خطوة بخطوة لحد ما يفتكرك بالاقتباسات على مدار اليوم 🚀

## إزاي تشغّل الأكواد؟

1. نزّل Python من [python.org](https://www.python.org/downloads/)
2. افتح الترمينال في مكان الملف
3. شغّل: `python hello.py`

## نصيحة 💡

متخفش تبوّظ الكود. غيّر فيه، شغّل، شوف النتيجة. كده بالظبط اللي بيتعلم بيها أي مبرمج.

خطوة بخطوة وانت كده مبرمج 🚀
